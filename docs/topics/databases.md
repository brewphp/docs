# Databases

BrewPHP supports **SQLite**, **MySQL** (and MariaDB) and **PostgreSQL**
through PHP's PDO extension. Connections are configured in the `DATABASES`
setting and opened on first use, so a page that never touches the database
never connects.

## Configuration

`DATABASES` maps connection names to settings. Models always use the
`default` connection.

```php title="config/settings.php"
'DATABASES' => [
    'default' => [
        'ENGINE' => env('DB_ENGINE', 'sqlite'),
        'NAME' => env('DB_NAME', 'storage/db.sqlite3'),
        'HOST' => env('DB_HOST', '127.0.0.1'),
        'PORT' => env('DB_PORT'),
        'USER' => env('DB_USER', ''),
        'PASSWORD' => env('DB_PASSWORD', ''),
    ],
],
```

| Key | Default | Meaning |
|---|---|---|
| `ENGINE` | `'sqlite'` | `'sqlite'`, `'mysql'` or `'pgsql'`. Django's names `sqlite3`, `postgresql` (and `postgres`, `mariadb`) work too. |
| `NAME` | `'storage/db.sqlite3'` for SQLite | SQLite: the database file, relative to the project folder, or `':memory:'`. MySQL and PostgreSQL: the database name. |
| `HOST` | `'127.0.0.1'` | Server host (not used by SQLite). |
| `PORT` | `3306` (MySQL), `5432` (PostgreSQL) | Server port. |
| `USER` | `''` | User name. |
| `PASSWORD` | `''` | Password. |
| `OPTIONS` | `[]` | Extra connection options (below). |

Without a `DATABASES` setting, a project uses SQLite in
`storage/db.sqlite3`. The skeleton reads every key from `.env`, so each
machine can use its own database without editing `settings.php`:

```ini title=".env"
DB_ENGINE=pgsql
DB_NAME=blog
DB_HOST=127.0.0.1
DB_PORT=5432
DB_USER=blog
DB_PASSWORD=secret
```

### OPTIONS

`OPTIONS` has two kinds of entries:

- **string keys** are added to the PDO DSN, for example
  `'sslmode' => 'require'` (PostgreSQL), `'unix_socket' => '/run/mysqld/mysqld.sock'`
  or `'charset' => 'utf8mb4'` (MySQL);
- **integer keys** are PDO attributes, for example
  `\PDO::ATTR_TIMEOUT => 5` or `\PDO::ATTR_PERSISTENT => true`.

```php
'OPTIONS' => [
    'sslmode' => 'require',
    \PDO::ATTR_TIMEOUT => 5,
],
```

## SQLite

SQLite needs no server: the database is a single file, which makes it the
best choice to start a project and for tests.

```php
'default' => [
    'ENGINE' => 'sqlite',
    'NAME' => 'storage/db.sqlite3',
],
```

- The folder of the file must exist; the file is created on first use.
- Keep the file out of git (the skeleton's `.gitignore` does).
- BrewPHP turns on SQLite's foreign key checks (`PRAGMA foreign_keys = ON`).
- `contains`, `startswith` and `endswith` are case-sensitive (they use
  `GLOB`); the `i...` lookups ignore case for ASCII letters only.
- Requires the `pdo_sqlite` extension.

## MySQL and MariaDB

```php
'default' => [
    'ENGINE' => 'mysql',
    'NAME' => 'blog',
    'HOST' => '127.0.0.1',
    'PORT' => 3306,
    'USER' => 'blog',
    'PASSWORD' => env('DB_PASSWORD'),
],
```

- Create the database with the `utf8mb4` character set; connections use
  `utf8mb4` unless `OPTIONS` sets another `charset`.
- Use MySQL 8.0+ or MariaDB 10.5+ (renaming columns needs them).
- Text comparisons follow the column collation, which is usually
  case-insensitive; `exact` may therefore ignore case, while `contains`,
  `startswith` and `endswith` are made case-sensitive with `LIKE BINARY`.
- Schema changes (`CREATE TABLE`, `ALTER TABLE`) are committed immediately
  and cannot be rolled back.
- Requires the `pdo_mysql` extension.

## PostgreSQL

```php
'default' => [
    'ENGINE' => 'pgsql',
    'NAME' => 'blog',
    'HOST' => '127.0.0.1',
    'PORT' => 5432,
    'USER' => 'blog',
    'PASSWORD' => env('DB_PASSWORD'),
],
```

- New primary keys are read with `INSERT ... RETURNING`.
- Case-insensitive lookups use `ILIKE`; `JsonField` uses `jsonb` and
  `UUIDField` the native `uuid` type.
- Schema changes run inside transactions and can be rolled back.
- Requires the `pdo_pgsql` extension.

## Column types per engine

| Field | SQLite | MySQL | PostgreSQL |
|---|---|---|---|
| `AutoField` / `BigAutoField` | `integer ... AUTOINCREMENT` | `integer` / `bigint AUTO_INCREMENT` | `integer` / `bigint GENERATED BY DEFAULT AS IDENTITY` |
| `CharField` | `varchar(n)` | `varchar(n)` | `varchar(n)` |
| `TextField` | `text` | `longtext` | `text` |
| `IntegerField` | `integer` | `integer` | `integer` |
| `BigIntegerField` | `bigint` | `bigint` | `bigint` |
| `FloatField` | `real` | `double precision` | `double precision` |
| `DecimalField` | `decimal(m, d)` | `decimal(m, d)` | `numeric(m, d)` |
| `BooleanField` | `bool` | `bool` (`tinyint(1)`) | `boolean` |
| `DateField` | `date` | `date` | `date` |
| `DateTimeField` | `datetime` | `datetime` | `timestamp` |
| `TimeField` | `time` | `time` | `time` |
| `JsonField` | `text` | `json` | `jsonb` |
| `UUIDField` | `char(36)` | `char(36)` | `uuid` |

## Several databases

Add more entries to `DATABASES` and use them by name with `db()`:

```php
'DATABASES' => [
    'default' => ['ENGINE' => 'sqlite', 'NAME' => 'storage/db.sqlite3'],
    'legacy' => ['ENGINE' => 'mysql', 'NAME' => 'old_shop', 'USER' => 'reader', 'PASSWORD' => env('LEGACY_PASSWORD')],
],
```

```php
$orders = db('legacy')->select('SELECT * FROM orders WHERE status = ?', ['open']);
```

Models and QuerySets use the `default` connection; other connections are
for [raw SQL](queries.md#raw-sql).

## Connections

`db()` returns a `BrewPHP\Db\Connection`, a thin layer over PDO:

```php
db()->engine();          // "sqlite", "mysql" or "pgsql"
db()->pdo();             // the PDO object (connects if needed)
db()->isConnected();
db()->disconnect();      // the next query reconnects
db()->schemaEditor();    // create and change tables, see Models
```

Its query methods (`select()`, `selectOne()`, `scalar()`, `statement()`,
`insert()`, `transaction()`) are described in
[Making queries](queries.md#raw-sql).

## Checking the configuration

`php manage.php check` verifies `DATABASES` without connecting:

| Id | Problem |
|---|---|
| `db.E001` | there is no `default` connection |
| `db.E002` | an entry is not an array or has an unknown `ENGINE` |
| `db.E003` | the PDO driver of an engine is not installed |

`php manage.php about` shows the engine and name of the default database.

## Testing

Use an in-memory SQLite database in tests: it is fast, starts empty for
every application you create, and needs no cleanup.

```php
use BrewPHP\Core\Application;
use BrewPHP\Core\Settings;

$app = new Application($projectPath, new Settings([
    'INSTALLED_APPS' => ['blog'],
    'DATABASES' => ['default' => ['ENGINE' => 'sqlite', 'NAME' => ':memory:']],
]));
$app->boot();

$editor = $app->db()->schemaEditor();
$editor->createModel(Author::class);
$editor->createModel(Post::class);
```
